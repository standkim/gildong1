1. 첫 번째 프로젝트: 『길동이의 코딩 일기』

#요구조건명세서

① HTML/CSS 기초 페이지 구조 요청

HTML과 CSS만 사용해서 웹사이트 기본 레이아웃을 만들어줘.  
상단에 ‘길동이의 코딩 일기’라는 제목과 내비게이션 메뉴(홈, 일기쓰기, 목록)를 추가하고,  
중앙에는 일기 내용을 작성할 수 있는 입력 폼을 만들어줘. 
예쁜 디자인보다는 간단하고 깔끔한 레이아웃이 좋아.  

② JavaScript로 다크모드 기능 추가하기

기존 HTML/CSS 코드에서 JavaScript를 사용해 '다크모드'를 구현해줘.  
상단에 다크모드를 켜고 끌 수 있는 버튼을 만들어서, 클릭하면 웹사이트 전체 테마가 밝고 어두운 모드로 전환되게 해줘.

③ JavaScript로 일기 저장(localStorage) 구현하기

자바스크립트로 일기 내용을 브라우저 localStorage에 저장하고,  
저장된 데이터를 페이지를 새로고침해도 유지되게 해줘.  
또한 저장된 일기 목록을 간단하게 보여주고, 클릭하면 내용을 확인할 수 있도록 해줘.

(선택사항) 추가 인터랙션 요청하기

JavaScript로 간단한 폰트 크기 조절 버튼을 추가해줘. 버튼을 누르면 글자가 커지거나 작아지는 기능이면 좋겠어.
